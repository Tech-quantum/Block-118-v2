# Block-118 (نسخه ۲) 🏢

سیستم مدیریت هوشمند برای یک ساختمان ۱۰ طبقه (۴۰ واحد). این پروژه با معماری کاملاً امن، مدرن و بدون نیاز به فیلترشکن (با استفاده از زیرساخت Vercel) طراحی شده و به صورت PWA (قابل نصب روی گوشی) کار می‌کند.

## 🌟 ویژگی‌های کلیدی

### 👑 پنل مدیریت (ادمین)
- **داشبورد جامع:** مشاهده آمار لحظه‌ای، وضعیت ۴۰ واحد و لیست بدهکاران.
- **مدیریت واحدها:** ویرایش نام مالک، وضعیت (خالی/ساکن) و مبلغ بدهی.
- **مدیریت مالی:** صدور شارژ (گروهی برای کل ساختمان یا تک‌نفره)، ثبت پرداخت‌ها و مشاهده تاریخچه تراکنش‌ها.
- **هزینه‌ها:** ثبت، ویرایش و حذف هزینه‌های جاری ساختمان (تعمیرات، نظافت و...).
- **درخواست‌های تعمیرات:** مشاهده عکس‌های ارسالی ساکنین، تغییر وضعیت و حذف نرم (Soft Delete) پس از انجام کار.
- **اطلاعیه‌ها:** ثبت پیام گروهی که در بالای داشبورد تمام ساکنین نمایش داده می‌شود.
- **پیام‌رسانی:** چت گروهی با همه یا چت اختصاصی با یک واحد خاص.
- **بکاپ‌گیری:** دانلود فایل JSON از کل اطلاعات دیتابیس برای جلوگیری از هرگونه خطر.

### 👤 پنل ساکنین
- **حریم خصوصی کامل:** هر ساکن فقط به اطلاعات واحد خودش دسترسی دارد.
- **امور مالی:** مشاهده بدهی/طلب خود، تاریخچه پرداخت‌ها و موجودی فعلی صندوق ساختمان.
- **ثبت درخواست:** ارسال درخواست تعمیرات همراه با **عکس** (عکس‌ها به صورت خودکار بهینه‌سازی و فشرده می‌شوند).
- **ارتباط با مدیر:** ارسال پیام به مدیر ساختمان و مشاهده اطلاعیه‌ها.
- **تنظیمات شخصی:** تغییر رمز عبور، انتخاب از بین ۵ تم رنگی و فعال‌سازی حالت شب (Dark Mode).

## 🛠 پشته فناوری (Tech Stack)
- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS, Lucide Icons
- **Backend (Serverless):** Vercel API Routes (Node.js)
- **Database & Auth:** Firebase Firestore & Firebase Authentication (از طریق REST API امن)
- **Hosting:** Vercel

---

## 🏗 معماری امنیتی (BFF Architecture)
برای دور زدن محدودیت‌های شبکه، مرورگر مستقیماً با سرویس‌های گوگل صحبت نمی‌کند. تمام درخواست‌ها از طریق APIهای امن در Vercel عبور می‌کنند:
`Client (Browser)  ➔  /api/* (Vercel)  ➔  Firebase Auth & Firestore`

- امنیت داده‌ها در لایه دیتابیس توسط `firestore.rules` تضمین می‌شود (نه در سمت کلاینت).
- توکن ورود (JWT) هر کاربر در هدر درخواست‌ها ارسال می‌شود و Vercel آن را با فایربیس تطبیق می‌دهد.

---

## ⚠️ محدودیت‌های مهم (برای توسعه‌دهندگان)
1. **سقف ۱۲ فایل API:** پلن رایگان Vercel اجازه ساخت بیش از ۱۲ فایل در پوشه `api/` را نمی‌دهد. در حال حاضر ۱۰ فایل داریم. **هرگونه قابلیت جدید باید داخل فایل‌های موجود ادغام شود.**
2. **عدم استفاده از Firebase Admin SDK:** به دلیل خطای ESM در محیط Vercel، از این پکیج استفاده نمی‌شود. تمام عملیات با `fetch` به REST API فایربیس انجام می‌شود.
3. **متغیرهای محیطی:** تنها متغیر موردنیاز در Vercel، کلید `FIREBASE_API_KEY` است.
